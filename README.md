# supercalc2026

## Задача

### Спринт 0. Сервис-калькулятор

Вашей команде необходимо реализовать сервис для «продвинутого» калькулятора.

Есть клиент с GUI (десктоп-/веб-/mobile-приложение), который может задавать любое
арифметическое выражение. Набор операций может быть ограничен.

### Например:

`(12 + 22*7) / (33 + (12*3 -8)) * 3`

Выражение в виде строки отправляется на сервис. Сервис может быть развернут локально.
Весь пересчет происходит на стороне сервиса.

Сервис умеет обрабатывать любое арифметическое выражение со стороны клиента и выводить
результат. Если в выражении есть ошибка (например, неверно выставлены открывающие и
закрывающие скобки), то сервис отправляет сообщение клиенту с ошибкой.

Сервис также хранит все предыдущие вычисления в базе данных. Клиент может запросить список
всех своих прежних вычислений. Список на стороне клиента должен быть «кликабельным».
Результаты работы должны быть представлены командой публично на практике в классе в виде
демо проекта: живой запуск программы или видео-ролик.

### Основные цели
- Оценить потенциал команды
- Проверить выбранный стек технологий
- Настроить рабочее окружение для командной работы
